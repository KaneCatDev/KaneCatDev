## Featured Projects

### 🎮 Gakeyru

Android application designed to find and track **PC video game deals**.

Built primarily with **Kotlin and Jetpack Compose**, integrating external services such as CheapShark and Steam. It includes search, filters, favorites, user accounts, price alerts, free-game notifications and multilingual support.

**Technologies:** Kotlin · Jetpack Compose · Room · Firebase · WorkManager · REST APIs

🌐 [Website](https://gakeyru.app/) · 📱 [Google Play](https://play.google.com/store/apps/details?id=dev.kanecat.gakeyru)

---

### ☁️ Hellies Cloud

Private cloud platform developed for the **Hellies Bar VRChat community**, allowing members to store, organize, preview and download shared resources through a familiar cloud-drive style interface.

Includes authentication, user management, file management and multimedia previews, with the service deployed on my own infrastructure.

**Technologies:** React · TypeScript · Node.js · Express · SQLite · Docker · Cloudflare

🌐 [View on my portfolio]([https://hellies.kanecat.dev/](https://kanecat.dev/projects/hellies-cloud))

---

### 🍸 Hellies Bar — VRChat World

Custom VRChat world developed for the **Hellies Bar community**.

The project includes environment design, role-based access systems, security tools, player management, interactive objects, custom UI, synchronized systems and performance optimization for VR.

I also create and adapt 3D assets and environments using Blender.

**Technologies:** Unity · C# / UdonSharp · VRChat SDK · Blender · Substance 3D Painter

🌐 [View on my portfolio]([https://kanecat.dev/](https://kanecat.dev/projects/mapa-hellies-bar))
