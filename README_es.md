## Proyectos destacados

### 🎮 Gakeyru

Aplicación Android diseñada para encontrar y seguir **ofertas de videojuegos para PC**.

Desarrollada principalmente con **Kotlin y Jetpack Compose**, integrando servicios externos como CheapShark y Steam. Incluye búsqueda, filtros, favoritos, cuentas de usuario, alertas de precios, notificaciones de juegos gratuitos y soporte multidioma.

**Tecnologías:** Kotlin · Jetpack Compose · Room · Firebase · WorkManager · REST APIs

🌐 [Página web](https://gakeyru.app/) · 📱 [Google Play](https://play.google.com/store/apps/details?id=dev.kanecat.gakeyru)

---

### ☁️ Hellies Cloud

Plataforma de nube privada desarrollada para la **comunidad de VRChat Hellies Bar**, permitiendo a sus miembros almacenar, organizar, previsualizar y descargar recursos compartidos mediante una interfaz familiar inspirada en servicios de almacenamiento en la nube.

Incluye autenticación, gestión de usuarios, gestión de archivos y previsualización de contenido multimedia, con el servicio desplegado en mi propia infraestructura.

**Tecnologías:** React · TypeScript · Node.js · Express · SQLite · Docker · Cloudflare

🌐 [Ver en mi portfolio](https://kanecat.dev/projects/hellies-cloud)

---

### 🍸 Hellies Bar — Mundo de VRChat

Mundo personalizado de VRChat desarrollado para la **comunidad Hellies Bar**.

El proyecto incluye diseño de entornos, sistemas de acceso basados en roles, herramientas de seguridad, gestión de jugadores, objetos interactivos, interfaces personalizadas, sistemas sincronizados y optimización de rendimiento para realidad virtual.

También creo y adapto recursos y entornos 3D utilizando Blender.

**Tecnologías:** Unity · C# / UdonSharp · VRChat SDK · Blender · Substance 3D Painter

🌐 [Ver en mi portfolio](https://kanecat.dev/projects/mapa-hellies-bar)
